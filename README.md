# testpoints-verse

Device test-point and ISP pinout images organized by **brand**, not collection source.

- `test-points/<brand>/...`
- `isp-pinouts/<brand>/<protocol>/...`
- `catalog.json` preserves source paths, aliases, hashes, dimensions, and provenance.
- `organization-report.json` records deduplication totals.

Duplicate images are stored once. Genuine alternative diagrams for one model are retained as `-tp-2`, `-tp-3`, `-isp-2`, and similar variants.
